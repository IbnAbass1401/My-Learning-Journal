ABOUT ME

Hi, my name is Tan. Welcome to my journal.

This is where I document my journey into software development, the things I'm learning, the projects I'm building, the problems I encounter and the lessons I pick up along the way.

MY STORY

How it all started.

I never planned to become a software developer when I started university. I'm currently studying Civil Engineering, but somewhere along the way, I became really interested in technology and started wondering what I could build with code.

I started with HTML and CSS because I wanted to understand how websites were actually made. Seeing something I wrote in my code editor appear in the browser made me want to keep learning.

As I continued, I moved into JavaScript and started building small projects. Eventually, I became more interested in understanding how complete applications work, which pushed me towards my goal of becoming a full-stack developer.

THE CHALLENGES

It hasn't always been easy.

Learning software development has been challenging, especially because I'm learning it alongside Civil Engineering.

JavaScript was one of the stages where things became noticeably harder. HTML and CSS felt more visual, but JavaScript required me to understand logic, variables, functions, conditionals, loops and the DOM.

There have also been plenty of bugs and moments where my code simply refused to work the way I expected. But I've started to understand that getting stuck is part of learning.

Instead of seeing every mistake as a setback, I'm learning to use those moments to understand what I don't know yet.

ME & TECHNOLOGY

I'm interested in building things.

What keeps me interested in software is the ability to take an idea and turn it into something people can actually use.

I'm currently building my foundation around HTML, CSS and JavaScript while gradually moving towards full-stack development.

In the future, I want to work with backend systems, APIs, databases, cloud technologies and other areas of software engineering. I'm also interested in exploring AI, machine learning and robotics as my knowledge grows.

I don't expect to understand everything at once. My goal is simply to keep learning, building and improving.

STAYING COMMITTED

Learn. Build. Get stuck. Repeat.

One thing I've learnt about myself is that consistency matters more than waiting until I feel motivated.

There are days when learning feels easy and there are days when I can spend hours trying to understand one small problem.

I keep going by focusing on the next thing I need to understand instead of worrying about how much I still have left to learn.

I also try to build instead of only watching tutorials. Projects force me to think, make mistakes, search for answers and actually use what I've learnt.

My goal isn't to rush the journey. It's to keep showing up.

WHAT'S NEXT

This is only the beginning.

I'm still a student, and I know there is a lot ahead of me. There are technologies I haven't touched yet, projects I haven't built and problems I haven't learnt how to solve.

But I'm excited about the process.

I want to become a strong software engineer, build serious products, work with other developers and continue exploring technology.

This journal is simply a record of that process.

Thanks for being here.
