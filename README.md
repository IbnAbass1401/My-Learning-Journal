# My Learning Journal

A personal learning journal documenting my journey into software development, from learning HTML and CSS to JavaScript, responsive design, and working toward full-stack development.

## Live Demo

[View the live website](https://my-learning-journal7.netlify.app/)

## About the Project

My Learning Journal is a personal website where I document what I learn while building my skills in software development.

The journal covers the different stages of my learning journey, including the challenges I faced, concepts I struggled with, projects I built, and lessons I picked up along the way.

Instead of only keeping track of what I learned, I wanted to have a place where I could look back and see how my skills and understanding developed over time.

## What's Inside

The journal currently includes:

- An About Me page
- 10 blog posts documenting my learning journey
- Responsive layouts for different screen sizes
- Individual pages for each blog post
- Navigation between pages
- Hero sections with background images
- A simple and clean reading experience

## Why I Built This

I built this project to document my progress while learning software development.

It also gave me a chance to practice turning what I was learning into something of my own instead of only following tutorials.

The journal is meant to show the process — including the parts that were difficult, the bugs I encountered, and the things that gradually started making sense.
