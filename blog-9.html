Why I'm Continuing Towards Full-Stack Development

Why learning frontend development made me curious about everything happening behind the interface.

The more I learnt about frontend development, the more curious I became about what happens behind the interface.

A website can have a beautiful frontend, but there is usually much more happening underneath it.

Where does the data come from?

How is it stored?

How does authentication work?

How does the frontend communicate with a server?

How are APIs built?

Those questions started pushing me toward backend development.

That's why I decided that I don't want to stop at frontend development.

I want to eventually become a full-stack developer who understands how the different parts of an application work together.

I'm continuing my learning through structured resources while building projects along the way.

There is still a lot for me to learn: backend development, databases, APIs, authentication, deployment and eventually more advanced areas of software engineering.

I don't want to pretend that I've mastered those things already.

I'm still learning.

But I think knowing where you want to go is important even when you're still taking the first steps toward it.

For now, I'm focused on becoming really solid with the fundamentals and continuing to build.

The plan is simple: learn → build → get stuck → debug → understand → build again.
