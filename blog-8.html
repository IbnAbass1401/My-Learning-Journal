Making My Projects Feel Like Mine

Moving beyond recreating tutorials and starting to build ideas of my own.

As I continued learning, I started wanting to move beyond simply recreating whatever project I was being taught.

I wanted to take the concepts and build something that actually felt like mine.

That's where I started experimenting with my own ideas.

I worked on an Ilorin tourist website featuring places such as the Ilorin Central Mosque, Esie Museum, Sobi Hill and other locations.

I also started working on a Nigerian restaurant concept called LocalBites.

Projects like these made development more interesting because I wasn't just thinking about whether the code worked.

I was thinking about the actual person who might use the website.

What should they see first?

How should the information be arranged?

What should happen on mobile?

How should the images look?

How can I make the design feel different from a generic template?

I also started paying more attention to the quality of the code and the overall structure of the project.

I'm still learning, so my projects aren't perfect.

But that's not really the point.

The point is that I'm gradually moving from:

learning how other people build things

to:

using what I've learnt to build my own things.

That is probably one of the biggest changes I've noticed in my journey so far.
