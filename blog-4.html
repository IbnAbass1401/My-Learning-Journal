JavaScript Was a Different Level

Moving from visual styling into programming logic, interaction and debugging.

When I moved from HTML and CSS into JavaScript, things became noticeably harder.

HTML and CSS felt more visual to me. I could change something and immediately see what happened.

JavaScript required me to actually understand logic.

I started learning about variables, functions, conditionals, loops, arrays, events and the DOM.

At first, some of these concepts felt confusing.

I remember having situations where my code technically looked right to me, but it wasn't doing what I expected.

One of the biggest things that helped was building projects.

I worked on a people counter, a password generator, a Chrome extension lead tracker and eventually a unit converter.

The unit converter was a good example of how much debugging is part of programming.

At one point, instead of getting the value I wanted, I ended up seeing things like [object HTMLInputElement] and NaN.

It turned out I was trying to perform calculations using the input element itself instead of the value inside it.

That kind of mistake taught me something that tutorials can't really teach on their own:

the error is part of the learning process.

I started becoming more comfortable with things like .value, .textContent, event listeners, querySelector, querySelectorAll and manipulating elements through JavaScript.

JavaScript was still challenging, but I started noticing something.

The more projects I built, the less mysterious the concepts became.

I wasn't suddenly an expert, but things that initially looked completely foreign started becoming familiar.

And that gave me the confidence to keep going.
