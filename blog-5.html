I Finally Started Understanding Responsive Design

Learning how layouts adapt instead of simply trying to make everything smaller.

For a while, I mostly thought about whether my website looked good on the screen I was using.

Then I started learning responsive design.

That changed the way I looked at websites.

A website isn't really finished just because it looks good on a laptop.

What happens when someone opens it on a 320px phone? What happens when the screen becomes wider? What happens when the navigation no longer fits?

What happens when a heading wraps onto three lines?

These were the kinds of questions I started thinking about.

I began learning about mobile-first design, media queries, breakpoints and responsive layouts.

CSS Grid became especially important.

I learnt about grid-template-columns, repeat(), gap, span, grid-column, grid-row and grid-template-areas.

I personally started preferring grid-column and grid-row in many situations because I found them more straightforward to understand.

One of the biggest things I learnt was that responsive design isn't simply about making everything smaller.

It's about allowing the layout to adapt.

An element might be beside another element on a desktop but move underneath it on a phone.

A three-column layout might become two columns and eventually one column.

The typography and spacing might change.

The navigation might need a completely different arrangement.

That was when responsive design started becoming more than just a CSS topic to me.
