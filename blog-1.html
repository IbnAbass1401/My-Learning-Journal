How I Started My Journey Into Software Development

The beginning of my journey into software development and why I decided to start building with code.

I never planned to become a software developer when I started university. I'm currently studying Civil Engineering, but somewhere along the way, I became really interested in technology and started wondering what I could build with code.

At first, I didn't know much about web development. I started with HTML and CSS because I wanted to understand how websites were actually made.

The beginning was simple. I was learning how to structure a webpage, add text and images, create links, and style different elements. But what made it interesting was being able to write something in my code editor and immediately see the result in the browser.

That feeling made me want to keep going.

I decided that I didn't want to learn software development only by watching tutorials. I wanted to actually build things, make mistakes, fix them, and understand why my code worked.

That became one of the biggest parts of my learning journey.

I started following structured learning resources while also building small projects alongside what I was learning. Some projects were very simple, but they helped me understand that knowing a concept and actually using it are two different things.

As I continued, I started becoming more interested in frontend development, and eventually I realized that I didn't just want to learn enough to make a few websites. I wanted to understand software development properly and eventually become a full-stack developer.

I'm still very much in the process of learning, but that's what makes this journey interesting.

This journal is where I'm documenting that process.
