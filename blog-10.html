This Is Only the Beginning

Looking back at how far I've come while knowing there is still much more to learn.

Looking back at where I started, I've learnt a lot more than I expected.

I started with HTML.

Then CSS.

Then JavaScript.

Then responsive design.

Along the way, I built small projects, broke things, fixed bugs, learnt from other developers and slowly became more comfortable writing code without someone telling me exactly what to do.

But I'm nowhere near finished.

I'm still a Civil Engineering student, and at the same time I'm building another path for myself in software development.

My long-term goal is bigger than simply being able to build websites.

I want to become a strong software engineer.

I want to build serious products, understand backend systems, work with APIs and databases, contribute to open source and eventually explore areas like AI/ML, cloud technologies and robotics.

I also want to gain real-world experience and work with other developers on problems that actually matter.

There will probably be plenty of difficult stages ahead.

There will be technologies that confuse me.

There will be projects that fail.

There will be bugs that take hours to solve.

But that's part of the process.

This Learning Journal is basically a record of that process.

I don't know exactly what this journey will look like years from now.

But I know that I'm going to keep building.

This is only the beginning.
